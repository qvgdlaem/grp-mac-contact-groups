# Changelog

## 0.6.1 — first public preview

- Introduces GRP — Groups for Apple Contacts, with a separate public bundle identity.
- Includes single-card and bulk group editing, all/some/none membership checkboxes,
  all/any/exclusion filters, Ungrouped and per-account browsing.
- Includes whole-card creation/modification sorting, richer contact rows, native
  editor handoff and confirmed card deletion.
- Uses solid black/white ordinary text and a numbered, contrast-adjusted Okabe–Ito
  palette for group families.
- Provides public build instructions, synthetic regression checks, native UI
  previews, and universal Apple Silicon/Intel packaging with checksums.

The preview uses ad hoc signing and is not Apple-notarized. Live behavior depends
on account/provider permissions; test writes with disposable contacts first.
